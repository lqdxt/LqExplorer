Like Roblox Studio's latest explorer design: New Gen Explorer.

This is NOT a revival of `Dex`, completely different project.

---

This is in beta, means that some things may not be added yet.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/lqdxt/LqExplorer/main/source/Explorer.luau"))()
```
