# Lq Explorer: Next Gen Explorer

An alternative for `Dex` Explorers.

Uses Roblox Studio's latest explorer design. Bored of the old one.

---

This is in beta, means that some things may not be added yet.

Lq Explorer:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/lqdxt/LqExplorer/main/source/Explorer.luau"))()
```

You can make plugins for it too, from the APIs it exposes.

> Still very active adding more unique stuff.
